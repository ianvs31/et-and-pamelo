# E.T. and Pomelo 画廊作品生成 Prompt

通用版 · 全身微缩棚景

```text
请用 $imagegen，基于我本次指定的猫照，生成一张 E.T. and Pomelo 画廊作品：把原照里最有趣的瞬间，重新搭成一个写实的白底摄影棚微缩场景。

【图像输入】
只把我本次指定的原照传给生图工具。画廊风格完全按下方文字执行，仓库参考图和之前生成的草稿都排除在图像输入之外。如果我上传了多张且没指定使用哪张，先问我选择，不要自行合并。

【先认出猫，再设计场景】
生成前，找出每只猫最容易辨认的两三个特征，例如脸型与眼神、白毛边界、额头或四肢上有辨识度的花纹。简短说明这些特征，并将具体描述写入实际生图指令，不能只写“保持同一只猫”。
保留猫的数量、成年或幼年观感、体型、毛色、耳形和表情。多只猫同框时，分别保留各自的特征、相对大小和互动，避免把花纹、身体或肢体混在一起。

【保留一个有趣瞬间】
从原照提取一个清楚的小情节，例如脸贴着暖气、两只前爪懒懒垂下、蜷在盆里，或挤在同一张垫子上。围绕猫的动作和它与道具的关系重新搭景。
可以调整视角、裁切、画幅、留白和道具尺寸，让情节更清楚。关键道具做成简洁、完整、有真实体积的小布景，其余环境省略。原照只有一个表情或姿态就足够有趣时，用最少的布景突出它。
如果我指定了新的道具、衣装或场景，按要求搭景，猫的身份仍以原照为准。

【全身入镜，缺失部位合理补全】
默认让每只猫全身入镜：耳尖、头部、完整躯干与后躯、四肢和尾巴都纳入画框，爪尖与尾尖留出边距。通过视角和姿态安排，让四肢及尾巴清楚可辨，同时保持自然的解剖关系。
原照被遮挡、被裁掉或没有拍全的身体部位，允许依据可见体型、毛色和花纹合理补全。补全部位应与原本可见的身体连续，比例自然；不新增肢体，不强行拉长躯干，不为露出四肢而扭曲动作。
优先使用开放的低台、浅盆或简洁承托道具，调整道具尺寸和拍摄角度，让身体自然露出。避免高侧板、厚围挡或过大的道具遮住大片躯干。保留原照里最有趣的动作和互动，无需机械复制原来的遮挡与裁切。
补全的隐藏部位属于合理创作，不声称其花纹与真实隐藏部位完全一致。若我明确要求局部特写或另有裁切，以本次要求为准。

【真实的白底摄影棚微缩场景】
成图像一张真实的摄影棚照片。猫有真实毛发、自然体态与身体重量；微缩感来自精简的布景、道具尺度和空间组织。猫仍然是有真实毛发的猫，不做成塑料、树脂、毛毡或卡通玩偶。
使用干净的白色无缝背景与地面、柔和棚拍光、适当留白和克制景深。猫的脸、身体、四肢及尾巴保持清晰可读。
布景要完整落地，有真实的台面或支撑、可辨的材质与自然阴影。猫与道具接触处有合理的承托、毛发轻微受压和接触暗部；道具与地面之间有投影。画面集中在一个小情节上。
不要沿猫的轮廓擦成白色，不要用任意白块遮住身体，不要出现抠图硬边、身体缺口、悬空或穿模。避免过度磨皮、锐化与虚化。除非我明确要求，不添加文字、画廊名称、Logo、水印、相框或多余装饰。

【先出一张，核对后保存草稿】
先生成一张。对照原照检查：
1. 猫的数量、身份特征、毛色分区、体型和表情是否保留。
2. 每只猫是否全身入镜，补全的身体、四肢和尾巴是否自然、完整。
3. 原照最有趣的瞬间是否还在，猫与道具的接触是否合理。
4. 布景是否完整落地，是否有抠图硬边、身体缺口、多余肢体或悬浮。
若猫的身份明显改变、全身要求未满足，或出现上述结构问题，标为“待重做”并指出具体差异；重做仍只使用指定原照。
展示预览，并将展示的同一份成图保存为草稿。简要说明核对结果以及哪些部位属于补全。等我明确确认发布后再发布；“这张可以”或“迭代一下 prompt”只表示认可效果或修改方向，不等于发布指令。
```
